# Método del Trapecio

Este repositorio contiene un programa en Python que implementa el método del trapecio para aproximar integrales definidas.

## Descripción

El método del trapecio es una técnica numérica para aproximar el valor de una integral definida. Este programa utiliza el método del trapecio para calcular la aproximación de la integral de una función específica en un intervalo dado.

## Cómo funciona

El código contiene una implementación del método del trapecio para aproximar integrales definidas. Utiliza una serie de subintervalos que se van duplicando desde 1 hasta 1024 para calcular la aproximación de la integral.
